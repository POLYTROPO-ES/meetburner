Privacy notice

Last updated: 23 November 2026.

MeetBurner is a live meeting-cost counter. It runs at meetburner.com and as a Windows and Linux desktop app; on macOS there is no virtual camera.

  • No account. You do not sign in, and MeetBurner collects nothing about you: no telemetry, no analytics and no crash reporting.
  • The web app stays in your browser. Settings are stored in the browser's local storage on that device. The app is served from Cloudflare Pages, and that is the only network request it makes.
  • Share links carry the data in the link. A share link carries the meeting summary in the URL fragment (#/share?...), which browsers do not send to a server.
  • The desktop app talks to no network service. The source webcam is used only locally; camera frames travel through local shared memory between the app and the virtual-camera driver.
  • The virtual camera is a per-user registration. Register webcam for meets writes a per-user COM registration under HKCU, with no administrator rights and no kernel driver. Clean webcam for meets removes it. Uninstalling the app removes it for the Windows account that runs the uninstaller; other accounts can use Clean webcam for meets.
  • No in-app update check. The desktop app does not check for updates. Users update from the Microsoft Store page or from the GitHub releases page.

Questions or problems: open an issue on the MeetBurner issue tracker.

Signing details are in the code signing policy.

Aviso de privacidad

Última actualización: 23 de noviembre de 2026.

MeetBurner es un contador de coste de reuniones en directo. Funciona en meetburner.com y como aplicación de escritorio para Windows y Linux; en macOS no hay cámara virtual.

  • Sin cuenta. No inicias sesión y MeetBurner no recoge nada sobre ti: sin telemetría, sin analíticas y sin informes de fallos.
  • La aplicación web se queda en tu navegador. Los ajustes se guardan en el almacenamiento local del navegador en ese dispositivo. La aplicación se sirve desde Cloudflare Pages, y esa es la única petición de red que hace.
  • Los enlaces para compartir llevan los datos en el propio enlace. Un enlace para compartir lleva el resumen de la reunión en el fragmento de la URL (#/share?...), que los navegadores no envían a ningún servidor.
  • La aplicación de escritorio no se comunica con ningún servicio de red. La webcam de origen se usa solo localmente; los fotogramas de la cámara viajan por memoria compartida local entre la aplicación y el controlador de cámara virtual.
  • La cámara virtual es un registro por usuario. Register webcam for meets escribe un registro COM por usuario en HKCU, sin permisos de administrador y sin controlador de kernel. Clean webcam for meets lo elimina. Desinstalar la aplicación lo elimina para la cuenta de Windows que ejecuta el desinstalador; las demás cuentas pueden usar Clean webcam for meets.
  • Sin comprobación de actualizaciones en la aplicación. La aplicación de escritorio no comprueba si hay actualizaciones. Las actualizaciones se descargan desde la página de Microsoft Store o desde la página de versiones de GitHub.

Si tienes preguntas o problemas, abre una incidencia en el gestor de incidencias de MeetBurner.

Los detalles de la firma están en la política de firma de código.
