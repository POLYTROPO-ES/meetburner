# Store screenshots

The Store accepts 1366×768 or 1920×1080 PNG. The current set:

| File | Size | What it shows |
|---|---|---|
| `01-setup.png` | 1920×1080 | The real Windows app: country, salaries, participants and counter style on the left, the live split-flap counter on the right, and the **Registered** camera status. |
| `02-counter.png` | 1366×768 | The real counter window at 1366×768: split-flap plates, total cost, elapsed, person-time and cost per minute. |
| `03-camera-picker.png` | 1366×768 | A real Jitsi Meet pre-join screen in Edge: **Settings → Video** with the camera list open and **MeetBurner Camera** selected; the preview is the live counter. |
| `04-overlay-schematic.png` | 1366×768 | **Schematic, not a screenshot:** how the counter card sits over a meeting video. Generated by `../overlay-schematic.ps1`; it is labelled in the image. |

## How the captures were made

- `01-setup.png` and `02-counter.png`: the real `apps/desktop/src-tauri/target/release/meetburner.exe`
  on Windows 11 with the DirectShow driver registered. The setup page was set to **Only counter**,
  the meeting was started, and the counter window was captured without its title bar at 1366×768.
- `03-camera-picker.png`: Edge with a clean profile and Jitsi Meet. `--use-fake-ui-for-media-stream`
  only auto-accepts the camera permission; the devices are real (the list also shows the physical
  webcams and OBS). The browser chrome and the flag warning were cropped out by capturing the page
  area. The counter in the preview is the live MeetBurner camera.
- `04-overlay-schematic.png`: run
  `pwsh -NoProfile -ExecutionPolicy Bypass -File docs/store/overlay-schematic.ps1`.
  Replace it with a real overlay capture when a suitable webcam is available; the image itself says
  it is a schematic.

## Rules

- Take the captures from a real build; never paste mockups as if they were screenshots.
- Do not promise features that are not in this release (for example, the macOS virtual camera).
- Keep each image at 1366×768 or 1920×1080 and under the Partner Center file-size limit.
- The Store logos come from `apps/desktop/src-tauri/icons/`; they are not part of this folder.
