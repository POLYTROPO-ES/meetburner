# 0004. Languages

- Status: accepted
- Date: 2026-10-22

## Decision

- Docs, code, comments and agent files: **English**.
- Apps (web, desktop, camera frame text): **English and Spanish**, auto-detected from `navigator.language`, switchable in the UI.
- Dictionary lives in `packages/core/src/i18n.ts` (plain object, no library). The Rust frame renderer receives already-translated labels from the UI.
